    tmux и vim: минимум для работы на серверах

    На сервере нет VS Code и вкладок терминала. Два инструмента решают это: vim — редактор, который есть везде, tmux — несколько окон в одном SSH и сессии, которые не умирают при обрыве связи.

    tmux

    Зачем

    • Сессия переживает обрыв SSH. Запустил долгую миграцию, отвалился Wi-Fi — переподключаешься и видишь её на том же месте.
    • Несколько окон и панелей в одном подключении: логи сверху, команды снизу.
    • Совместная работа: два человека подключаются к одной сессии и видят один экран.
    sudo apt install tmux    # или brew install tmux

    Сессии

    tmux                          # новая сессия
tmux new -s deploy            # новая сессия с именем
tmux ls                       # список сессий
tmux attach -t deploy         # подключиться к сессии (коротко: tmux a -t deploy)
tmux kill-session -t deploy   # закрыть сессию

    Префикс

    Все команды внутри tmux начинаются с префикса Ctrl+b: нажать Ctrl+b, отпустить, затем клавишу.

    Клавиши Действие
    Ctrl+b d отключиться от сессии (она продолжит работать)
    Ctrl+b c новое окно
    Ctrl+b n / p следующее / предыдущее окно
    Ctrl+b 0..9 окно по номеру
    Ctrl+b , переименовать окно
    Ctrl+b % разделить панель вертикально
    Ctrl+b " разделить панель горизонтально
    Ctrl+b стрелки переход между панелями
    Ctrl+b z развернуть панель на весь экран (и обратно)
    Ctrl+b x закрыть панель
    Ctrl+b [ режим прокрутки (выход — q)
    Ctrl+b s список сессий для переключения

    Типичный сценарий:

    ssh prod-db
tmux new -s migration
./long-migration.sh          # идёт долго…
# Ctrl+b d — отключились, можно закрыть ноутбук
# …позже
ssh prod-db
tmux a -t migration          # миграция всё ещё здесь

    Минимальный ~/.tmux.conf:

    set -g mouse on              # прокрутка и переключение панелей мышью
set -g history-limit 50000   # больше истории прокрутки
set -g base-index 1          # окна с 1, а не с 0

    Альтернатива попроще — screen (есть на старых серверах): screen -S name, отключиться Ctrl+a d, вернуться screen -r name.

    vim

    Главное: режимы

    Vim ведёт себя странно, пока не знаешь про режимы:

    Режим Как попасть Что делает
    Normal Esc команды и перемещение (здесь vim открывается)
    Insert i обычный ввод текста
    Visual v выделение текста
    Command : команды: сохранить, выйти, заменить

    Если непонятно, что происходит, — жми Esc пару раз. Ты в Normal.

    Выжить: открыть, поправить, сохранить

    vim /etc/nginx/nginx.conf
i            → начать редактировать
...правки...
Esc          → выйти из режима ввода
:w           → сохранить
:q           → выйти
:wq          → сохранить и выйти (или ZZ)
:q!          → выйти БЕЗ сохранения

    Нет прав на запись, а уже всё отредактировал: :w !sudo tee % — сохранить через sudo.

    Перемещение (Normal)

    Клавиши Действие
    h j k l влево, вниз, вверх, вправо (стрелки тоже работают)
    w / b на слово вперёд / назад
    0 / $ начало / конец строки
    gg / G начало / конец файла
    :42 или 42G на строку 42
    Ctrl+d / Ctrl+u полэкрана вниз / вверх

    Редактирование (Normal)

    Клавиши Действие
    i / a вставка перед / после курсора
    o / O новая строка ниже / выше и вставка
    x удалить символ
    dd удалить (вырезать) строку
    5dd удалить 5 строк
    yy скопировать строку
    p вставить после курсора
    u отменить
    Ctrl+r повторить отменённое
    . повторить последнее действие

    Поиск и замена

    /error          → искать вперёд; n — следующее, N — предыдущее
?error          → искать назад
:%s/old/new/g   → заменить во всём файле
:%s/old/new/gc  → с подтверждением каждой замены
:set number     → показать номера строк
:set paste      → режим вставки из буфера без «лесенки» отступов

    Минимальный ~/.vimrc:

    set number          " номера строк
syntax on           " подсветка
set expandtab       " пробелы вместо табов (кроме Makefile!)
set tabstop=2 shiftwidth=2
set hlsearch        " подсвечивать найденное

    Не хочешь vim — на большинстве серверов есть nano: подсказки по клавишам внизу экрана, Ctrl+O — сохранить, Ctrl+X — выйти. Но vim есть везде, даже в минимальных образах, поэтому базу стоит знать.

    Частые ошибки

    Симптом Причина Решение
    Не могу выйти из vim не в Normal-режиме Esc, затем :q!
    При вставке в vim съезжают отступы YAML автоотступ во время вставки :set paste перед вставкой
    Закрыл терминал — процесс умер запускал без tmux/screen запускать долгие задачи в tmux (или nohup cmd &)
    Ctrl+b не работает внутри tmux на сервере tmux внутри tmux (локальный + удалённый) нажать Ctrl+b дважды — префикс уйдёт во вложенный

    Best Practices

    • Всё долгое на сервере — в tmux: миграции, бэкапы, apt upgrade.
    • Называй сессии (tmux new -s name) — через неделю не вспомнишь, что в сессии 3.
    • Перед правкой конфига — копия: cp nginx.conf nginx.conf.bak, затем проверка (nginx -t) после правки.
    • Не редактируй руками то, что управляется Ansible/Terraform — правка затрётся при следующем прогоне.
