    Шпаргалка: сети в Docker Compose

    Компактная памятка. Полное объяснение — на странице Сети в Docker Compose.

    Объявление сети + подключение сервиса

    networks:
  backend-net: {}        # объявления на верхнем уровне
  frontend-net: {}

services:
  nginx:
    networks:            # ВАЖНО: множественное число networks
      - backend-net
      - frontend-net

    Внутри одной сети контейнеры доступны по имени сервиса (menu-service, redis). В разных сетях — не видят друг друга.

    Изоляция frontend от бэкенда (паттерн)

    Сервис Сеть
    frontend frontend-net (изолирован)
    nginx frontend-net + backend-net (мост)
    menu / order / redis backend-net

    Ключевые факты

    • Имя ключа — networks: (с буквой s). network: — ошибка additional properties.
    • Без networks: сервис попадает в дефолтную сеть проекта → «все со всеми», нет изоляции.
    • Внутренний DNS 127.0.0.11 доступен только в кастомных (bridge) сетях.
    • При нескольких репликах имя резолвится в несколько IP.

    DNS + масштабирование (динамический резолвинг)

    Статический proxy_pass «залипает» — резолв 1 раз при старте, реплики не обновляются без рестарта:

    # ❌ nginx закеширует IP при старте
proxy_pass http://menu-service:8000;

    Динамический — через переменную + resolver (подхватывает реплики без рестарта):

    http {
    resolver 127.0.0.11 valid=10s;   # Docker DNS, обновлять каждые 10с

    location /api/menu {
        set $menu_backend http://menu-service:8000;
        proxy_pass $menu_backend;    # ✅ резолв на каждый запрос
    }
}

    Переменная без URI-части → nginx передаёт бэкенду тот же URI, что пришёл в location. rewrite не нужен.

    Драйверы

    Драйвер Когда
    bridge по умолчанию, почти всегда нужен только он
    host нужен прямой доступ к портам хоста (редко)
    overlay только в Docker Swarm
    none полностью без сети

    Быстрые команды

    docker network ls                                # список сетей (включая compose-сети)
docker network inspect <name>                    # детали сети, подключённые контейнеры
docker compose ...                               # сети создаются/удаляются сами

    Частые ошибки

    Симптом Причина Фикс
    additional properties 'network' not allowed network: вместо networks: networks:
    сервисы не видят друг друга по имени разные/дефолтная сеть общая сеть
    nginx не видит новые реплики статический proxy_pass переменная + resolver 127.0.0.11
    nginx 502 имя сервиса не существует или в другой сети проверить имя + общую сеть
