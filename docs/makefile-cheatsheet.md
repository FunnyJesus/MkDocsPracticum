# Makefile: шпаргалка

Самое частое при чтении и написании Makefile.

> Теория и примеры — [Makefile (теория)](makefile.md).

## Топ-20

| # | Категория | Синтаксис / команда | Что делает |
|---|---|---|---|
| 1 | запуск | `make` | выполнить цель по умолчанию (первую или `.DEFAULT_GOAL`) |
| 2 | запуск | `make build test` | выполнить несколько целей по очереди |
| 3 | запуск | `make deploy ENV=prod` | передать/переопределить переменную |
| 4 | отладка | `make -n deploy` | dry-run: показать команды, не выполняя |
| 5 | отладка | `make -B build` | пересобрать принудительно, игнорируя даты |
| 6 | запуск | `make -C dir target` | запустить make в другой директории |
| 7 | правило | `target: deps` + строка с TAB | цель, зависимости, рецепт |
| 8 | правило | `.PHONY: test clean` | цели-команды, а не файлы |
| 9 | правило | `.DEFAULT_GOAL := help` | что запускать по голому `make` |
| 10 | переменные | `VAR := value` | присвоить сразу (основной вариант) |
| 11 | переменные | `VAR ?= value` | значение по умолчанию, если не задано извне |
| 12 | переменные | `VAR += more` | дописать к значению |
| 13 | переменные | `$(VAR)` | подставить значение |
| 14 | функции | `$(shell git rev-parse --short HEAD)` | результат shell-команды |
| 15 | авто | `$@` / `$<` / `$^` | цель / первая зависимость / все зависимости |
| 16 | рецепт | `@echo ...` | не печатать саму команду |
| 17 | рецепт | `-rm file` | игнорировать ошибку команды |
| 18 | рецепт | `$$HOME`, `$$f` | `$` для shell, а не для Make |
| 19 | рецепт | `cd dir && cmd` | каждая строка — отдельный shell |
| 20 | правило | `out: in | dir` | order-only: `dir` нужен, но его дата не важна |

## Шаблон для нового проекта

```makefile
.DEFAULT_GOAL := help
.PHONY: help install test build clean

help: ## Список целей
	@grep -E '^[a-zA-Z_-]+:.*## ' $(MAKEFILE_LIST) \
		| awk 'BEGIN {FS = ":.*## "}; {printf "  %-10s %s\n", $$1, $$2}'

install: ## Зависимости
	pip install -r requirements.txt

test: install ## Тесты
	pytest -q

build: test ## Сборка
	docker build -t myapp .

clean: ## Уборка
	rm -rf build dist
```

## Этот репозиторий

```bash
make            # список целей
make serve      # http://127.0.0.1:8000
make strict     # проверить сборку перед push
make clean
```
