# Bash: шпаргалка топ-20 конструкций

Самое нужное для написания скриптов на bash. Быстрые конструкции для повседневной автоматизации.

> Подробные примеры и объяснения — [Bash scripts](bash-scripts.md).

## Топ-20 конструкций

| # | Конструкция | Что делает |
|---|---|---|
| 1 | `#!/usr/bin/env bash` | shebang — запуск через bash |
| 2 | `var=value` | задать переменную (без пробелов вокруг `=`) |
| 3 | `$var`, `${var}` | использовать переменную |
| 4 | `$@`, `$1`, `$#` | аргументы скрипта (все / первый / число) |
| 5 | `cmd1 \| cmd2` | пайп — вывод cmd1 → ввод cmd2 |
| 6 | `cmd1 && cmd2` | cmd2 выполнится, только если cmd1 успешен |
| 7 | `cmd1 \|\| cmd2` | cmd2 выполнится, только если cmd1 упал |
| 8 | `if [ -f file ]; then ... fi` | условный оператор |
| 9 | `for i in list; do ... done` | цикл по списку/диапазону |
| 10 | `while read line; do ... done` | цикл по строкам/считать |
| 11 | `case $x in a) ...;; *) ...;; esac` | множественный выбор |
| 12 | `func() { ...; }` | объявление функции |
| 13 | `$(...)` | подстановка результата команды |
| 14 | `(cmd)` | подпроцесс — временный контекст |
| 15 | `set -euo pipefail` | режимы: стоп на ошибке, незаданные переменные, пайпы |
| 16 | `$?` | код возврата предыдущей команды (0 = успех) |
| 17 | `-eq`, `-ne`, `-lt`, `-gt` | сравнение ЧИСЕЛ |
| 18 | `-f`, `-d`, `-z`, `-n` | проверки: файл/каталог/пустая/непустая |
| 19 | `[[]]` vs `[]` | расширенная vs POSIX проверка (в `[[]]` можно `&&`,`\|\|`,регэкспы) |
| 20 | `chmod +x script.sh` | сделать скрипт исполняемым |

## Мини-шаблон скрипта

```bash
#!/usr/bin/env bash
set -euo pipefail          # безопасные режимы по умолчанию

INPUT="${1:-default}"      # аргумент с дефолтом
echo "Запуск для: $INPUT"

if [ -f "$INPUT" ]; then   # проверка файла
  grep -i "error" "$INPUT"
else
  echo "Файл $INPUT не найден"
  exit 1
fi
```

## Цикл + обработка строк

```bash
# по диапазону
for i in {1..5}; do
  echo "Номер $i"
done

# по строкам из команды
while read -r line; do
  echo "Строка: $line"
done < <(cat file.txt)
```

## Сравнение чисел и строк

```bash
# числа
[ "$a" -eq 0 ] && echo "a == 0"
[ "$a" -gt 5 ] && echo "a > 5"

# строки (в [[]])
[[ "$name" == "alice" ]] && echo "Привет, Alice"
[[ "$name" == *.log ]] && echo "это лог"
```

## Надёжность (set + trap)

```bash
set -euo pipefail   # умрёт на первой ошибке
trap 'echo "Прервано!"; exit 1' INT  # обработка Ctrl+C
```
