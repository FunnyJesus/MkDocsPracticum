    Linux: шпаргалка топ-20 команд

    Самое частое, что нужно в повседневной работе девопса/разработчика. Минимум слов — максимум пользы.

    Полный справочник команд: Linux: команды с подробным описанием. Теория — Linux (теория).

    Топ-20 команд

    # Категория Команда Что делает
    1 файлы ls -la список файлов, включая скрытые, подробно
    2 файлы cd <dir> перейти в каталог
    3 файлы cp -r src dst скопировать (рекурсивно)
    4 файлы mv src dst переместить / переименовать
    5 файлы rm -rf <dir> удалить каталог принудительно ⚠️
    6 чтение cat <file> вывести файл целиком
    7 чтение tail -f <file> следить за логами в реальном времени
    8 поиск grep -r "text" . рекурсивный поиск текста
    9 поиск find . -name "*.conf" поиск файлов по имени
    10 права chmod +x file сделать файл исполняемым
    11 права chown user:group file сменить владельца
    12 пр.доступ sudo <cmd> выполнить с правами root
    13 процессы ps aux \| grep <name> найти процесс
    14 процессы kill -9 <PID> принудительно завершить процесс
    15 мониторинг htop (или top) живой монитор процессов
    16 сеть ss -tulpn слушающие порты и процессы
    17 сеть curl -v <url> запрос к серверу с подробностями
    18 диск df -h свободное место на дисках
    19 диск du -sh <dir> размер каталога
    20 сервисы systemctl status <svc> статус сервиса

    Компактные примеры

    # Файлы и директории
ls -la
cp -r ./src /backup/src
mv old.txt new.txt
rm -rf ./tmp_build

# Анализ логов / поиск
tail -f /var/log/nginx/error.log
grep -i "exception" app.log
grep -rn "TODO" ./src

# Процессы
ps aux | grep java
kill -9 12345
htop

# Сеть и порты
ss -tulpn | grep 8000
curl -v http://localhost:8000/health
ping -c 4 ya.ru

# Диск
df -h
du -sh /var/log

# Сервисы и права
systemctl status nginx
systemctl restart nginx
sudo chmod +x deploy.sh

    Мини-шпаргалка по синтаксису

    cmd1 && cmd2      # cmd2 выполнится только если cmd1 успешен
cmd1 || cmd2      # cmd2 выполнится только если cmd1 упал
cmd1 | cmd2       # вывод cmd1 → ввод cmd2 (пайп)
cmd > file        # записать stdout в файл
cmd 2>&1          # ошибки направить туда же, куда stdout
$?                # код возврата последней команды (0 = успех)
